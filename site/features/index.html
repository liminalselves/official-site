Features · 功能

功能

互动、对话、表情、聊天，以及 Windows 与 Android 上的常驻方式与自动更新。

Features · 特性

让她留在桌面上

角色使用官方 Live2D Cubism Web SDK 渲染，互动与聊天在 Windows 与 Android 上表现一致。

  1. 01

    互动

    Interaction

    摸头、戳脸、碰耳朵，不同的触碰方式有不同的反应和台词。

  2. 02

    对话

    Dialogue

    按早晚时段问候，配合对话气泡，偶尔自言自语。

  3. 03

    表情与情绪

    Emotions

    内置 12 种表情，心情随互动变化。

  4. 04

    聊天

    Chat

    登录阈界人格社区账号，与 Aliya 智能体对话，可保留多个会话。

  5. 05

    Windows 桌面常驻

    Windows Presence

    透明置顶窗口、托盘菜单、贴边吸附，支持开机自启。

  6. 06

    Android 悬浮窗

    Android Overlay

    退到后台后转为悬浮窗，可贴边停靠，支持省电模式。

  7. 07

    自动更新

    Auto Update

    每次启动自动检查更新，Windows 版可在应用内一键更新。

开始使用

支持 Windows 10 及以上与 Android 8.0 及以上。
